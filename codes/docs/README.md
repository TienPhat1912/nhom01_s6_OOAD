# Tài liệu dự án

Bắt đầu với [hướng dẫn chạy project](../README.md) để clone, cấu hình và chạy demo. Mã nguồn, scripts và tài liệu đều nằm trong `codes/`; tài liệu đồ án ở `codes/docs/`. Tên thư mục chạy và tên nhánh Git đều là `codes`.

| Nội dung | Tài liệu |
|---|---|
| Cài đặt chi tiết, SQL Express/Docker, kịch bản demo | [Demo guide](instructions/demo-guide.md) |
| Kết nối Docker sau khi chuyển dữ liệu, EF CLI và bản sao lưu | [SQL Server Docker](instructions/sql-server-docker.md) |
| Kiến trúc và phụ thuộc giữa các project | [Architecture](instructions/architecture.md) |
| Schema, quan hệ, migration | [Database design](instructions/database-design.md) |
| Endpoint, xác thực và lỗi | [API](instructions/api-documentation.md) |
| Transaction, cạnh tranh, notification outbox | [Giải thích kỹ thuật](instructions/technical-explanation.md) |
| UI và design tokens | [Design system](instructions/phase4-design-system.md) |
| Yêu cầu và use case | [Requirements review](instructions/requirements-review.md), [ma trận UC/BR](instructions/usecase-coverage.md) |
| Kết quả nghiệm thu trước đây và giới hạn | [Phase 8](instructions/phase8-verification.md) |
| File đã gom khỏi cấu trúc chạy | [Archive](../../archive/README.md) |

Các báo cáo Phase 3–8 và tiến độ được giữ để đối chiếu đồ án. Log/ảnh cũ đã chuyển vào archive cục bộ; kết quả mới được sinh bằng các script kiểm thử. Không dùng kết quả lịch sử để khẳng định một bản clone mới đã được kiểm chứng.
